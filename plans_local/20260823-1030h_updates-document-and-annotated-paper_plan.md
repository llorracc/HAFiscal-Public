## 4. Phase U3 — the annotated paper build (no frozen bytes touched)

Mechanism: a **build variant**, not an edit. `make pdf-annotated`:
- A wrapper layer at the `\fetchgeneratedtabular`/include seam: for each exhibit
  whose file appears in an `annotations manifest` (generated by U2), the annotated
  build wraps the FROZEN content with a marginal badge — "updated: see UPDATES §x.y"
  — plus a hyperlink; optionally an appendix that reprints the updated exhibit from
  the `_candidate` file, clearly labeled NOT-AS-PUBLISHED.
- Implementation: a `\ifannotated` toggle + one small style file; the frozen .tex
  files are read, never written; the annotated PDF writes to
  `HAFiscal-annotated.pdf` (never `HAFiscal.pdf`).
- The freeze guard is untouched; a CI check asserts the annotated build leaves the
  manifest hashes intact.
